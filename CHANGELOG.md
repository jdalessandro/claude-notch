# Changelog

All notable changes are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/).

## [0.2.0] - Unreleased

### Changed
- **The island is now a macOS Live Activity (ActivityKit, macOS 27.3+)** drawn by the system, replacing the custom AppKit
  overlay. Allow / Deny, Open and Done are App Intents that run inside the app and are matched to the exact request,
  so a stale or duplicated tap is ignored. The activity state is a small, tested, size-budgeted `NotchActivityState`.
- The app is a menu-bar agent; the island is its main surface.
- **Expanded island, Apple Music style**: the agent count and needs-you / working / subagent badges sit up beside the
  cutout, the most urgent permission request or question is a featured card (Allow / Deny, or its answer options with
  Answer in Claude / Not now), and session cards show branch, status, a live timer, subagent, lines-changed and context
  stats. Even 24 pt insets on every edge.
- **Compact island**: the logo and a waveform with one bar per working agent, driven by a once-a-second beat from the
  app (Live Activities can't animate on their own); amber when something needs you.
- **Paging**: sessions come in pages with a ‹ › pager in the footer; pages turn by themselves, hold after a tap, and
  jump back to the first page when something new needs you.
- **Open** deep-links to the session's conversation in Claude Desktop, or brings its terminal forward.
- **Plan limits from Anthropic's usage endpoint** (the request Claude Code's `/usage` makes, with Claude Code's own
  login), polled about every five minutes. The island's footer shows the 5-hour and weekly limits on one line, with an
  hourglass and a Claude Desktop–style reset countdown on each (5-hour in hours and minutes, weekly in days) and one
  refresh button that re-reads the usage API. The status line is now optional.
- Context-window sizes come from Claude's cached model catalog instead of a guess.
- Build: `ClaudeNotch.xcodeproj` is generated by `scripts/gen_xcodeproj.py` (app + widget extension + hook); the pure
  core and the hook stay in SwiftPM. CI covers the SwiftPM part (hosted runners lack the macOS 27.3 SDK).

### Removed
- The AppKit panel and its settings: island style and width, collapsed style, hide when idle, compact/detailed toggle,
  hover expansion and delay, auto-open duration, and dwell-based auto-review. The system owns the island's layout and
  interaction. Old preference files still load; the keys are ignored.
- The Reviewed / Done button on finished sessions: a result is marked reviewed when you open or reply in that session.
- The old island's Limits | Tokens toggle; the footer always shows plan-limit percentages.

### Added
- **Island size** setting (General): five steps from Smaller to Larger scale the island's text and icons; the two
  largest show two session cards per page.
- `make snapshots` renders the island views from the demo data to `docs/screens/` (`ClaudeNotch --snapshot <dir>`).
- Release packaging: `scripts/release.sh` (Developer ID signing, notarization, dmg, GitHub Release), a Homebrew cask
  template and a workflow that updates the tap when a release is published.

## [0.1.0] - Unreleased

### Added
- Dynamic-Island-style overlay for the MacBook display cutout (floating or attached), with a collapsed
  tile + waveform and an expanded view that groups sessions by what needs you.
- Per-session prompt, current tool, subagent tree, context meter, and the result of finished turns.
- Compact and detailed expanded views, switchable from the island header; the last-used view is remembered.
- Approve or deny tool permissions from the island.
- Plan-limit usage in the style of Claude Desktop (5-hour, weekly, per-model weekly) as percentage bars, with a
  Limits | Tokens toggle for token totals (last 5 hours, today, 7 days). Dollar cost is hidden on subscription plans.
- Settings window: island style and width, hover behavior, content, notifications, integration, diagnostics.
- `claude-notch-hook` forwarder with `--install`/`--uninstall`/`--statusline`, merging safely into
  `~/.claude/settings.json`.

### Review
- Results are marked reviewed automatically when you reply in that session or deliberately view the full result in the
  island for a few seconds (opt-out in Settings); manual **Open** / **Mark reviewed** remain.

### Subagents and questions
- Per-session subagent stat ("2 running · 1 done") on every session in both views, alongside the global header count.
- Fixed sessions showing **Idle** while background subagents were still working: the main turn's `Stop` no longer
  force-closes subagents, the session stays Working until the last one stops, and the "finished" notification waits.
- Subagent tree: running-first ordering, per-session expand/collapse, current tool, tool-call counts, last result,
  and a running-subagent count in the headers. Silent subagents are settled after 15 minutes.
- Claude's questions (`AskUserQuestion`) render as questions with their choices and friendlier actions and notifications.

### Rendering
- Claude's replies render inline markdown (bold, code, links) with block syntax flattened; subagent hand-backs, task
  notifications and system reminders no longer replace your real prompt; worktree and scratch-workspace sessions get
  readable names; a detached `HEAD` is not shown as a branch.
- Narrower island (320 / 350 / 420 pt presets, 320 pt compact view); clicking a compact row opens it in the detailed view.
- The last reported plan limits are remembered across restarts.

### Reliability
- Per-field lenient hook payload decoding (the status line's object-valued `model` no longer drops the event).
- Hook forwarder deadlines and payload truncation; ordered, deadline-bounded IPC; safe reply-handle lifecycle.
- Held approvals are released only by events that settle them; answering a gone hook is a no-op.
- Installer guards: symlinks, permissions, unexpected shapes, no-op writes, concurrent-edit detection, exact-name matching.
- Usage de-duplicated globally across transcripts; quota windows clamp, normalize timestamps, and expire locally.
